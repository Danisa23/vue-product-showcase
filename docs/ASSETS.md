# Recursos visuales

El proyecto utiliza recursos locales para asegurar consistencia visual, disponibilidad y ausencia de imágenes repetidas entre los ocho productos del catálogo.

- `laptop.webp` → laptop
- `headphones.webp` → audífonos
- `smartphone.webp` → smartphone
- `smartwatch.webp` → smartwatch
- `keyboard.webp` → teclado
- `mouse.webp` → mouse
- `tablet.webp` → tablet
- `webcam.webp` → webcam
- `hero-techstore.webp` → composición tecnológica del hero

El logo está disponible con fondo transparente en SVG y PNG, con versiones para fondo oscuro y claro.
